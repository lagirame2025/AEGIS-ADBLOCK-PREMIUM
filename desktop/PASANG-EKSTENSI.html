🛡 Pasang ekstensi Aegis di browser

Folder ekstensi ada di sebelah berkas ini: chromium (Chrome, Edge, Opera, Brave, Vivaldi), firefox, dan safari (sumber untuk macOS).

Chrome, Edge, Opera, Brave, Vivaldi

  1. Buka halaman ekstensi: chrome://extensions (Edge: edge://extensions, Opera: opera://extensions, Brave: brave://extensions).
  2. Aktifkan Mode pengembang (Developer mode).
  3. Klik Muat yang belum dibuka / Load unpacked lalu pilih folder chromium di sebelah berkas ini.
  4. Sematkan ikon 🛡 di toolbar. Klik untuk membuka panel (saklar fitur, statistik, perbarui daftar).
Jangan hapus folder chromium setelah dipasang, karena browser membacanya dari sana.

Firefox

  1. Cara cepat (sementara, hilang saat Firefox ditutup): about:debugging#/runtime/this-firefox → Load Temporary Add-on → pilih manifest.json di folder firefox.
  2. Permanen: tandatangani berkas ext-firefox.zip (gratis) lewat addons.mozilla.org/developers sebagai add-on “tidak terdaftar” (unlisted), lalu pasang berkas .xpi hasilnya. Firefox rilis menolak add-on yang belum ditandatangani; Firefox Developer/Nightly/ESR bisa memasang yang tak bertanda tangan bila xpinstall.signatures.required = false.
  3. Setelah dipasang, buka about:addons → Aegis → Izin, dan izinkan akses data di semua situs.

Safari (macOS)

  1. Butuh Mac dengan Xcode. Di Terminal: xcrun safari-web-extension-converter safari --app-name Aegis --macos-only (jalankan di folder ini).
  2. Build proyek Xcode yang dihasilkan, lalu aktifkan di Safari → Pengaturan → Ekstensi.
  3. Safari iOS: pilih target iOS pada konverter, lalu pasang lewat Xcode/TestFlight (perlu akun pengembang Apple).

Catatan

Perlindungan DNS (daemon Aegis di Windows) dan ekstensi saling melengkapi: DNS memblokir iklan/judol/scam di semua aplikasi, ekstensi menangani iklan yang berasal dari domain yang sama dengan konten (YouTube, media sosial, popup, komentar judol, tautan scam).
